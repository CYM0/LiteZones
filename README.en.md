# LiteZones 1.0.0 (轻格)

[English](README.en.md) | [简体中文](README.md)

**Windows 10/11 x64 · MIT License**

LiteZones (轻格) is a lightweight desktop window manager that arranges application windows into reusable screen zones with a quick Shift-and-drag gesture. Use the notification-area menu to manage layouts and appearance.

**This software and this page were created entirely by AI.**

### Features

- Preview zones while dragging; release the mouse to snap a window into place.
- Choose from six built-in layouts or create up to 12 custom layouts for each display.
- Resize custom zones by dragging dividers or entering pixel dimensions.
- Swap managed windows, fill occupied zones, and restore a window's original size when dragging it out.
- Adjust zone spacing, preview opacity, color themes, and visible edge compensation.
- Choose whether LiteZones starts with Windows.
- Switch between English and Simplified Chinese from the notification-area menu. On first launch, LiteZones follows the Windows UI language: Chinese uses Simplified Chinese and other languages use English. Manual choices are saved.

### Use LiteZones

1. Run LiteZones.exe.
2. Find the LiteZones icon in the Windows notification area.
3. Hold Shift while dragging a window to preview the layouts.
4. Release the mouse while still holding Shift to snap the window. Releasing Shift first cancels the snap.

Right-click the notification-area icon to select a display and layout, edit custom layouts, change appearance, switch language, or exit. Drag a managed window out of its zone without Shift to detach it; by default, it returns to its original size.

### Settings and compatibility

LiteZones saves layouts, appearance, and language preferences in %APPDATA%\LiteZones\settings.ini. Window assignments last until LiteZones closes or the display arrangement changes. The app runs locally without an account or network connection. Some elevated, protected, full-screen, or minimum-size-restricted windows may not be repositioned precisely.
