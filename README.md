# 轻格 LiteZones 1.0.0

[简体中文](README.md) | [English](README.en.md)

**Windows 10/11 x64 · MIT 许可证**

轻格（LiteZones）是一款轻量级桌面窗口管理工具。按住 Shift 拖动窗口即可预览并吸附到屏幕分区，通过通知区域菜单管理布局和外观。

**本软件及此页面完全由AI制作。**

### 功能

- 拖动窗口时预览分区，松开鼠标后吸附到目标区域。
- 提供 6 种内置布局；每台显示器可创建并保存最多 12 套自定义布局。
- 在布局编辑器中拖动分割线或输入像素尺寸，调整自定义分区。
- 交换已管理的窗口、将窗口放入占用区域，并在拖出分区时恢复原始尺寸。
- 调整分区间距、预览透明度、颜色主题和窗口可见边缘补偿。
- 选择是否随 Windows 启动。
- 在通知区域菜单中直接切换英文和简体中文。首次启动时读取 Windows UI 语言：中文界面使用简体中文，其他语言使用英文；手动切换后的选择会保存。

### 使用轻格

1. 运行 LiteZones.exe。
2. 在 Windows 通知区域找到 LiteZones 图标。
3. 按住 Shift 拖动窗口，预览可用布局。
4. 持续按住 Shift 并松开鼠标，窗口才会吸附；提前松开 Shift 会取消本次吸附。

右键通知区域图标，可以选择显示器和布局、编辑自定义布局、调整外观、切换语言或退出。未按 Shift 将已管理窗口拖出分区时，窗口会解除归属；默认情况下会恢复到吸附前的尺寸。

### 设置与兼容性

布局、外观和语言设置保存在 %APPDATA%\LiteZones\settings.ini。窗口与分区的对应关系会在 LiteZones 关闭或显示器排列改变时清除。轻格在本机运行，无需账户或网络连接。部分管理员权限窗口、受保护窗口、全屏窗口或有最小尺寸限制的窗口可能无法精确调整。
